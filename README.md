# MUSHROOM ID WEBSITE
## Process
This mushroom identification website was built using many different platforms and debugged by hand and with the help of copilot.
1. I started by creating a visual system in Adobe that I would later send to AI so it could recreate my visual language consistently across the website.
2. I then went to Figma to build the barebones structure of the website, establishing layouts, components, and overall page hierarchy.
3. Next, I figured out how to export the raw code from Figma, which I then used to edit and debug in VS Code.
4. I noticed that Figma generated some files I hadn’t worked with before, such as CSS and TypeScript (.ts) files. Understanding these files and how they worked became crucial for integrating my designs and preparing the project for GitHub deployment.
5. Before pushing to GitHub, I used GitHub Copilot alongside manual coding to ensure the exported code matched the visual language I had developed in Adobe and Figma.
6. Pushing to GitHub was the most challenging part of my process. I worked iteratively with Copilot and hand-edited code to ensure Vite files were correctly recognized and deployed on GitHub Pages. (Had to use npm run deploy to push)
8. Throughout this process, I learned the importance of bridging design and development, combining visual thinking with code debugging to create a functional, visually consistent website.
9. Finally, I tested the live site, verified all assets were loading correctly, and confirmed that the GitHub Pages deployment matched the intended design and functionality.

## Limitations
- The API I used had a lot of restrictions including the amount of times I could use the AI Identification and the amount of data I could display
- I think if I were to develop this project further I would look for different data bases to help build upon my API

## Areas of Improvement
- I would also expand my website to have multiple pages with different interactions instead of just the home page
- I also think two of my buttons are not fully functional, but I prioritized the identification as it was the main element of my project
- I also think I could develop the visual language further, maybe adding a bit more character
